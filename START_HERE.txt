DWG2 Recomp v03 Alpha

New installation: extract the entire player ZIP, run START_DWG2.exe and select
your own supported original USA Xbox360 ISO. The launcher prepares it locally.
No separate compiler/toolchain installation is required. Import is only needed once.

Existing v01/v02/local installation: close the game and launcher. Extract this
ZIP separately, then run PowerShell:

  .\apply-update.ps1 -GameFolder 'C:\path\to\your\installation' -Package $PWD

Run START_DWG2.exe in your existing folder afterward. A changed native build may
prepare once using the already imported game; saves/settings stay in place.
v02 cannot detect v03 automatically because the updater first ships in v03.

v03 checks public GitHub releases in the background on startup. Help > Check for
Updates performs a manual check. Cross/A accepts; Circle/B declines. Accepting
downloads a verified update, then waits until the game and launcher close before
installing and restarting. Save your progress before quitting. You can keep
playing after declining. Internet access is optional for normal play.

Automatic save selects slot01 on recognized dedicated save screens using the
original save operation. Missing/invalid containers retain normal recovery UI.
Never close the game while it is writing a save.

Menus: File (Pause/Resume, Restart, Quit), View (Fullscreen,1x/2x/3x resolution,
HUD seam correction), FOV (Default..+50%,5%steps), Controls, Help.
True1.5x1080p is not included in this release. Known music/background-crash
issues remain under investigation. No game data is included in the download.
